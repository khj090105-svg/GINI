# 책이랑 — 학교협동조합 온라인 중고책 서점

알라딘 중고책 판매 기능을 참고한 독립형 React 웹앱 MVP입니다. 입점 사업자, 정액제 콘텐츠, 쿠폰, 마일리지 기능은 포함하지 않습니다.

## 기능
- 도서 목록, 카테고리, 제목/저자/출판사/ISBN 검색, 가격/제목 정렬
- 중고 도서 상세 정보와 품질 등급/가격/상태 설명
- 장바구니, 주문 접수, 온라인 결제(데모 흐름), 현장 결제 선택
- 학교 내 지정 장소 직접 수령만 지원 (택배 없음)
- 주문 내역 조회
- 협동조합용 도서 등록/판매 중지/재개 및 주문 상태 관리 데모
- 브라우저 `localStorage`에 데이터 저장
- 모바일 반응형 UI

## 실행 방법
필요: Node.js 18 이상 권장

```bash
npm install
npm run dev
```

터미널에 표시되는 로컬 주소(보통 `http://localhost:5173`)를 브라우저에서 여세요.

프로덕션 빌드 확인:
```bash
npm run build
npm run preview
```

## GitHub에 올리기
1. GitHub에서 새 저장소를 만듭니다.
2. 압축을 푼 폴더 안에서 아래 명령을 실행합니다.

```bash
git init
git add .
git commit -m "Initial Chaekirang used-book store MVP"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
git push -u origin main
```

## 중요: 데모 한계 및 실제 서비스 전 필수 작업
- 온라인 결제는 **실제 PG 결제가 아닙니다.** 주문 흐름만 기록하며 결제 승인/취소를 처리하지 않습니다.
- 회원가입/로그인, 학교 이메일 인증, 관리자 인증이 아직 없습니다. 현재 관리자 메뉴는 누구나 열 수 있는 데모 화면입니다.
- 데이터는 현재 브라우저의 `localStorage`에만 저장됩니다. 다른 사용자/기기와 공유되지 않고 브라우저 데이터 삭제 시 사라질 수 있습니다.
- 실제 운영에는 서버/API, 데이터베이스, 학교 구성원 인증, 관리자 권한 검증, 결제대행사(PG) 연동, 주문 알림, 개인정보 처리방침 및 이용약관이 필요합니다.
- 도서 표지 이미지는 외부 Unsplash 이미지를 예시로 사용합니다. 실제 상품에는 해당 책의 표지 및 실물 사진을 등록하세요.
- 예시 도서/가격은 데모용이며 실제 재고를 뜻하지 않습니다.
